## 2. Key Architecture & Features Delivered

### A. Question Bank Authoring Workspace
- **Modular Studio Architecture**: Split the authoring studio into four clean subcomponents (each strictly under 400 lines):
  1. `QuestionBankListTab.tsx`: Paginated question bank browser with subject badges, marks, negative marking, and usage indicators (`✨ Fresh (Unused)` vs `⚠️ Previously Asked`).
  2. `PublishedTestsTab.tsx`: Directory of generated mock tests with access key statuses.
  3. `QuestionFormModal.tsx`: Question authoring modal with dynamic option builder (`+ Add Option`), live LaTeX formula preview, and optional diagram URLs.
  4. `ManualMockTestModal.tsx`: Multi-subject mock test builder allowing administrators to hand-pick $n$ questions across subjects, set duration and marks, and immediately publish.
- **Protected Question Deletion**: Prevents deletion of any question that is already part of an active or published mock assessment.

### B. LaTeX Mathematical Formula Engine (`MathRenderer.tsx`)
- Integrated `katex` and `react-katex`.
- Created a robust parser capable of evaluating inline math (`$E = mc^2$`), display blocks (`$$\int_{0}^{\infty} e^{-x^2} dx$$`), and chemical equations with graceful fallback if syntax is malformed.

### C. 6-Digit Numeric Access Key Engine
- **Access Key Protocol**:
  - Requires students to obtain and enter an active 6-digit numeric key (e.g., `849201`) generated by their faculty mentor or exam administrator before entering the exam room.
  - Active collision detection ensures no two tests share the same active key.
  - Strictly valid for 60 minutes with clear visual countdowns.
  - No automatic regeneration upon expiry; new keys must be explicitly authorized by teachers or admins.

### D. Anti-Cheat Security Shield & Test Runner Engine
- **Full-Screen Enforcement (`ExamSecurityShield.tsx`)**: Prompts the student to enter full-screen mode before delivering questions. Exiting full-screen triggers a warning and logs telemetry.
- **Shortcut & Context Menu Lockdown**: Disables right-click context menu, DevTools shortcuts (`F12`, `Ctrl+Shift+I`, `Ctrl+U`), copy/paste actions, and logs browser tab switches.
- **Persistent Anti-Cheat Countdown Timer (`ExamHeader.tsx`, `examStorage.ts`)**: Timer computes remaining duration directly from the initial server/local `startedAt` timestamp. Refreshing or reopening the browser window does **not** reset or extend the timer.
- **Auto-Submission on 00:00:00**: When time expires, the engine locks inputs and automatically triggers final submission without requiring student action.
- **4-State Question Palette (`ExamQuestionPalette.tsx`)**: Color-coded tracking:
  - `Not Visited` (Grey)
  - `Unanswered` (Amber/Orange)
  - `Attempted` (Emerald)
  - `Marked for Review` (Purple)

### E. Batch CSV Student Onboarding & Dynamic Credentials
- Created `TeacherStudentUpload.tsx` allowing faculty members to upload a Class 12 student roster via CSV or Excel (`Full Name`, `Email`, `Admission Number`, `APAAR ID`, `Phone`).
- Dynamic credential generation formula:
  - **Email**: Student's official email address.
  - **Password**: `${studentFirstName}@${schoolCode}` (e.g., `Aarav@JPS2026`).
- Automatic generation of printable credentials slips for classroom distribution.

### F. Mobile App QR Gating for Diagnostic Results
- Upon exam submission, the web client displays a congratulatory completion screen with a high-resolution QR code directing students to download the **School Connect Mobile App**.
- Deep diagnostic analytics, percentile graphs, and question-level dwell time solutions are gated behind the mobile app to drive mobile adoption.
